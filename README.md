# Behavior Coach

一套开源的 AI 行为教练方法论，来自「必作于易」的长期实践。

它不是待办清单，也不是监督你“更自律”。核心思路是：

> 行为做不出来，优先检查行为设计，而不是责怪人。

这套方法关注：

- 愿望与真实动机
- 过程性身份
- 锚点
- 最小行动
- 成功体验 / 庆祝
- 加码念头
- 刻意最小挑战
- 失败后的行为回路复盘
- 反向行为设计

## 免费使用

你不需要购买「必作于易」会员，也可以直接使用这套开源方法论做行为改变。

### 方式一：任何普通 AI 都能用

适合豆包、DeepSeek、Kimi、通义千问等普通聊天产品。

1. 打开 `references/methodology.zh-CN.md`
2. 复制全文
3. 新建一个对话，先粘贴方法论
4. 再告诉 AI：你现在真正想改变什么

如果平台支持“智能体 / 自定义指令 / 角色设定”，把完整方法论放进去，之后就不用每次重复粘贴。

建议开场：

> 请完整遵循我提供的行为教练方法论。不要把我当成需要监督的人，也不要擅自提高最低标准。先根据我现在的真实情况，帮我找到一个最值得解决的行为卡点。

### 方式二：支持 Agent Skills 的客户端

如果你使用支持开放 Agent Skills 的客户端，可以直接安装：

```bash
npx skills add simoncoper/Behavior-Coach
```

安装后，遇到拖延、微习惯、身份设计、锚点、最小行动、加码念头、失败复盘等问题时，让 Agent 使用 `behavior-coach`。

> 注意：普通豆包 / DeepSeek / Kimi 网页聊天并不需要运行这条命令。对这些产品，直接复制方法论或放进智能体系统指令最简单。

## 仓库结构

```text
Behavior-Coach/
├── SKILL.md
├── references/
│   └── methodology.zh-CN.md
└── README.md
```

- `SKILL.md`：标准 Agent Skill 入口
- `references/methodology.zh-CN.md`：完整行为教练方法论，也是核心真源

## 一个重要原则

这套方法不追求让你“每天做更多”。

它更关心：

> 你能不能找到一个自己真心愿意成为、又不会因为只做一点就觉得“不配”的身份，
> 再让一次次足够小的真实行动成为这个身份的证据。
